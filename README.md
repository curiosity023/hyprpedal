# hyprpedal
Support for the Olympus Multimedia Foot Switch RS series.

Reach peak multitasking with hyprpedal!
It gives your Hyprland setup an easy way to configure the Olympus RS series foot
switch (others will work but are not supported) for multitasking, coding, editing
videos, or really anything with custom keybinds!

hyprpedal is also offered as a solution for linux treating the Olympus RS series as
a mouse pointer device. hyprpedal will stop the foot switch from inputing RMB, LMB,
or MMB.

#  Installation

** hyprpedal is in a pre-release alpha development testing stage. This script
involves some kernel-side configurations, so proceed at your own risk.
Usage of unsupported switches (RS27 or RS31) is not reccommended until
guaranteed support is given. **
*It's reccommended to use a USB adapter on the 8-Pin Mini DIN Jack instead of
plugging it in to a docking station, for compatability reasons.*
